# 从句嵌套结构总览设计

## 目标

让长难句讲解先呈现完整句法层级，再逐项解释各从句，减少读者自行拼合嵌套关系的负担。

## 触发条件

仅在一句包含两层以上的从句嵌套、多个从句的并列归属不清，或修饰范围容易误判时使用。简单单层从句不增加结构图。

## 输出位置与格式

在 `## 语法讲解` 内先给出 `### 基本句型`，随后按需增加 `### 结构总览`，再讲具体从句。

结构总览使用纯文本代码块：以主句为外层骨架，用方括号标出从句边界，用缩进和连线标注“从句类型 + 句法功能／修饰对象”。多层嵌套的标签须贴近各自结构，保持层级对应。

## 边界

结构图只呈现原句实际存在的结构。解释性的完整形式、省略来源及存在歧义的还原放入后续分析，不混入结构图，也不把可能的还原写成唯一来源。

## 验证标准

- 复杂嵌套句会生成结构总览。
- 简单单层从句不会为形式完整而生成结构图。
- 每个标签能明确对应一个结构边界。
- 结构图不引入原句中不存在的 `so that` 等推测性结构。
